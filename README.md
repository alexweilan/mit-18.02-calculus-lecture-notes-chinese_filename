# MIT 18.02SC 多变量微积分讲义

本仓库整理并重新命名了 MIT OpenCourseWare 课程 **18.02SC Multivariable Calculus, Fall 2010** 的讲义与阅读资料，方便按官方 Session 编号检索和阅读。

> **非官方说明：** 本仓库不是 MIT 或 MIT OpenCourseWare 官方仓库，也不代表 MIT 对本仓库的认可或推荐。

## 资料范围

- 根目录：**34 份** MIT Lecture Notes 精选讲义。
- `Session补充讲义`：**71 份** Session 页面及资源索引中的阅读材料和示例。
- 合计：**105 份唯一 PDF**。
- 课程共有 102 个 Session；其中 82 个 Session 至少有一份本仓库收录的 PDF。
- Session 22、23、31、33、41、44、45、46、59、61、73、75、85、95、96、97、99、100、101、102 在官方课程中没有对应的讲义或阅读型 PDF，仅有视频、习题、解答或复习资料等其他资源。

核对范围覆盖 MIT 的 Lecture Notes 汇总页、全部 Session 页面，以及资源索引中所有 `notes`、`MNotes` 和 `we_*` PDF。官方资源中有一份 Session 45 的 `MNotes_p` 与本地“第87讲 扩散方程”内容完全相同，因此没有重复收录。
